🌾 AgriML — AI Model Architecture Flowchart

Intelligent Fertilizer Recommendation System
Stage 1
Data Input
📋
User Input Parameters
Nitrogen (N) · Phosphorus (P) · Potassium (K) · Soil pH · Soil Moisture (%) · Temperature (°C) · Rainfall (mm) · Humidity (%) · Crop Type (10 crops) · Land Area (hectares)
10 Input Features
Stage 2
Preprocessing
🔧
Missing Value Imputation
Mean imputation for numeric features, Mode imputation for categorical (crop type)
📏
Min-Max Normalization
Scale all numeric features to [0, 1] range using computed min/max parameters
🔤
One-Hot Encoding
Encode 10 crop types into binary feature columns (crop_Rice, crop_Wheat, etc.)
📊
Feature Extraction
Combine 8 numeric + 10 encoded features into a single 18-dimensional feature vector
18-D Feature Vector
Stage 3
ML Models
🌲
Random Forest Classifier
Algorithm: Ensemble of 15 Decision Trees
Split Criterion: Gini Impurity
Sampling: Bootstrap (bagging)
Feature Subset: 60% random per split
Max Depth: 12 · Min Samples: 3
→ Fertilizer Type + Confidence %
📈
Gradient Boosting Regressor
Algorithm: 50 Sequential Decision Stumps
Split Criterion: Mean Squared Error (MSE)
Learning Rate: 0.1 (shrinkage)
Training: Residual-based sequential fitting
Max Depth: 4 per stump
→ Yield (t/ha) + Confidence + RMSE
Stage 4
Optimization
⚙️
Fertilizer Optimizer
Nutrient deficit calculation (N/P/K)
Quantity per hectare (kg) & total
Cost estimate (₹) & environmental impact score
Composite optimization score (yield 40% + env 30% + cost 30%)
Quantity + Cost + Env Score
⚠️
Risk Predictor
7 Risk Categories:
Over-Fertilization · Nutrient Imbalance · Low Yield · pH Stress · Drought Stress · Nutrient Leaching · Temperature Stress
Each risk: severity + probability + recommendation
Risk Score (0–100)
🌤️
Climate Engine
7-day weather forecast simulation
Rainfall, temperature & humidity analysis
Quantity adjustment multiplier
Best application day recommendation
Timing Advisory
Stage 5
Analytics
🌍
Sustainability Score
6 Weighted Components:
Fertilizer Efficiency (20%) · Soil Balance (15%) · Environmental Score (20%) · Water Impact (15%) · Soil Health Trend (15%) · Carbon Footprint (15%)
Grade: A/B/C/D/F + eco-recommendations + badges
Grade A–F
🏥
Soil Health Tracker
Historical nutrient tracking (localStorage)
Linear trend projection (6-month)
Per-nutrient health scoring (0–100)
Degradation alerts & recommendations
Health 0–100
🔮
Scenario Simulator
"What-If" analysis engine
6 preset scenarios: ±30% fertilizer, drought, heavy rain, heat wave, optimal conditions
Delta comparison: yield / cost / env impact
What-If Analysis
Stage 6
Learning Loop
🧠
Adaptive Learning System
Records predictions vs. actual outcomes
Computes per-crop correction factors
Blended adjustment: 70% model + 30% learned
Builds personal farmer profiles over time
Self-Improving
🔄
Feedback Loop
Farmer submits actual yield & satisfaction (1–5 rating)
Accuracy tracking per crop
Trend analysis: improving / stable / declining
Feeds corrections back to model predictions
Continuous Improvement
↻ Corrections feed back to ML Models (Stage 3)
Stage 7
Output
🎯
Comprehensive Recommendation Output
Final combined result delivered to the farmer with full explainability
🧪 Fertilizer Type 📦 Quantity (kg/ha) 💰 Cost Estimate (₹) 🌾 Yield Prediction (t/ha) ⚠️ Risk Assessment 🌍 Sustainability Grade 🌤️ Climate Advisory 💡 Explainable AI Reasoning
AgriML · Client-Side ML Pipeline · Built with JavaScript · No Server Dependencies
