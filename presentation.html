Model 1: Random Forest Classifier
Fertilizer type recommendation using ensemble of decision trees
How It Works
  • Bootstrap Sampling — each tree gets random sample (with replacement)
  • Random Feature Subset — 60% features per split for diversity
  • Gini Impurity — measures split quality at each node
  • Majority Vote — final prediction aggregates all 15 trees
  • Confidence Score — % of trees agreeing on the top class
  • Class Probabilities — from aggregated leaf node counts

Model 2: Gradient Boosting Regressor
Yield prediction using sequential weak learners (decision stumps)
Algorithm Steps
  • Initialize prediction with mean of all target yields
  • For each of 50 estimators:
  •   a) Compute residuals (actual – prediction)
  •   b) Fit a decision stump (depth 4) on residuals
  •   c) predictions += learning_rate × stump output
  • Confidence = 1 – (RMSE / target std deviation)
  • Output: yield (t/ha), confidence, RMSE

Optimization Layer
Calculating optimal quantity, cost, and environmental score
💊 Quantity Optimization
  • Compute N, P, K deficits vs crop profile
  • Quantity = max deficit / nutrient % × 100
  • Capped at 20–500 kg/hectare
  • Scales by user's land area
💰 Cost Estimation
  • Cost = quantity × cost-per-kg
  • Per-hectare and total cost
  • 7 fertilizers with real market rates
  • Supports ₹ INR currency
🌍 Environmental Impact
  • Over-application penalty (+15)
  • High rainfall leaching risk (+20)
  • Soil acidification risk (+15)
  • High moisture runoff risk (+10)
  • Quantity-proportional impact (+0-40)
Climate-Aware Decision Engine
7-day weather forecast modifies recommendations in real-time
🌦️ Climate Impact Analysis
  • Generates 7-day weather forecast (temp, rain, humidity, wind)
  • Analyzes next 5 days for application window
  • Heavy rain (>50mm) → reduce qty by 15%
  • Moderate rain (>25mm) → reduce by 8%, split application
  • High temp (>35°C) → apply early morning
  • High humidity (>80%) → monitor for fungal diseases
  • Best Application Day scored by conditions

Adaptive Learning & Feedback Loop
Continuous improvement through farmer feedback
🧠 Adaptive Learning
  • Records every recommendation with input + predicted output
  • Stores up to 200 recommendations in localStorage
  • Farmer submits actual yield → computes correction factor
  • Correction = actual_yield / predicted_yield (per crop)
  • Blends: 70% model + 30% learned correction
  • Blend weight grows with more feedback (max 30%)
  • Accuracy tracked: within 20% = 'correct'
  • Builds personal profiles per crop
📝 Farmer Feedback
  • Submit: actual yield, fertilizer used, satisfaction (1-5)
  • Accuracy = 1 − |predicted − actual| / predicted
  • Trend analysis: first-half vs second-half accuracy
  • Per-crop accuracy breakdown
  • Status: Awaiting → Learning (1+) → Active (5+)
  • Data persisted (last 50 entries)
